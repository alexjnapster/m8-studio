M8 Studio 2 is a local menu-bar companion for your Samsung LS32BM801UIXUA and MacBook Air M2. Ukrainian is the default. Change Language in Settings for English; the choice is saved.

Your everyday controls

Click the display icon in the menu bar for brightness, available speaker volume and favorite scenes. Right-click it for a native quick-action menu. Option-scroll over the icon adjusts brightness by one percentage point. Open Studio for the full workspace.

Display offers available 60 Hz HiDPI and native modes, screen identification and the main-screen setting. A new mode reverts after 15 seconds unless you keep it. An independent recovery helper also protects a preview if the main app stops responding.

Scenes save a display’s mode, software brightness and available speaker volume. Preview before applying, favorite a scene, duplicate it, export or import JSON, undo removal, or undo the last applied scene. Profiles remain separate from scenes.

Brightness and keyboard

The slider currently controls visible software dimming, from 20% to 100%, independently for each screen. Link screens to change them together. This does not lower the physical backlight or create HDR headroom. Restore all screens removes dimming and stops experiments.

Global shortcuts: ⌃⌥⌘ ↑ / ↓ volume, ⌃⌥⌘ M mute, ⌃⌥⌘ ← / → brightness, ⌃⌥⌘ 0 restore, ⌃⌥⌘ Space open Studio. These work without Accessibility permission.

To use the Mac’s physical volume/brightness keys, enable media keys in Settings and grant M8 Studio Accessibility access in macOS. Volume commands are intercepted only while Samsung is the active audio output and the model-verified local audio service is available. Other output routes keep normal behavior. Hold Option with a media key for fine steps.

Best image quality for this connection

The panel is physically 3840 × 2160 at up to 60 Hz. HiDPI changes the logical workspace and render buffer; it does not turn this into a 5K or 120 Hz panel. “Larger text” uses 1920-wide HiDPI when available; “Balanced” uses 2560-wide HiDPI; native 4K uses smaller text without the same scaling.

Keep the original Samsung ColorSync profile as the starting point. The bundled M8 baseline is the original profile saved from this Mac, not a colorimeter calibration. sRGB reference is appropriate only when the physical picture settings match sRGB; assigning it to a different display response may reduce accuracy. A larger color-space name does not expand the panel’s gamut.

For critical work: warm up the display, stabilize room lighting, set software brightness to 100%, disable automatic picture enhancement while measuring, then measure your individual unit with a colorimeter. Import the resulting RGB ICC profile in Color. Every applied profile has readback verification and an undo action. White point, gamma, luminance and Delta E cannot be certified from EDID or screenshots.

Text/chroma, grayscale/clipping, gradients, solid pixels and geometry patterns are visual checks. Escape closes them. They do not measure calibration or establish bit depth.

Samsung’s M80B eManual says external HDR is not supported over USB-C on this generation. A compatible HDMI connection and Input Signal Plus are required to investigate HDR. The current app hides unavailable HDR switches. The panel’s brightness and lack of local dimming still constrain HDR contrast; software cannot remove those limits.

Sound that matches the hardware

The current Core Audio route reports stereo PCM, 2 channels at 48 kHz. The app controls the monitor’s actual network volume and mute with readback, rather than adding an arbitrary digital gain layer. Left/right checks play short low-level tones.

Compare Standard and Adaptive Sound+ in the monitor’s Sound settings at matched listening levels. A higher sample rate does not itself improve these speakers. No measured optimal EQ is bundled.

Dolby Atmos through this exact monitor speaker/USB-C route has not been verified. A shared Samsung manual listing Atmos for some models is not evidence that this unit supports it. The app does not show an Atmos toggle or claim to generate height channels. HDMI passthrough requires a compatible playback app and capable receiving audio device.

Connection, experiments and privacy

Find the monitor in Remote or enter its private local IP address. Choose Allow on the monitor’s M8 Studio request. The app checks the Samsung monitor model family before pairing, pins the local WebSocket certificate, and stores the pairing token in macOS Keychain. Ad-hoc development builds have different identities and may need to pair again. Keep the app on a trusted local network; volume control uses local UPnP HTTP.

The current cable path did not answer DDC/CI. IP Remote on port 1516 became reachable after you enabled it, but picture control has not yet passed a verified read/write/readback test on this M80B. Unsupported controls stay out of the interface. You can still reach Samsung’s own picture and sound menus with the remote after pairing.

Labs offers optional software brightness following, an evening schedule, and the menu-bar scroll gesture. Following copies a brightness value, not measured luminance. The schedule supports overnight periods and uses the Mac’s clock; manual adjustments pause automation for 30 minutes. Restore all screens stops the experiments.

No analytics, cloud account or audio/screen recording. Diagnostics and scene files are saved only when you choose to export them. Local preferences stay on the Mac. Open at login is optional. The app is locally signed for this Mac, not a notarized commercial release.
